# Community Hub

Community Hub is a Progressive Web App (PWA) companion for Discord communities.  
It helps organize **events, tasks, resources, and announcements**, complementing Discord rather than replacing it.

## Features (MVP)
- Discord OAuth login
- Dashboard with upcoming events, tasks, and announcements
- Resource management
- Task assignment and reminders
- Notification badges (in-app)

## Tech Stack
- Frontend: HTML, CSS, JavaScript (vanilla for MVP)
- Backend: Supabase
- Auth: Discord OAuth
- Push notifications: Firebase
- Hosting: Netlify
- PWA-enabled for mobile and desktop
